    <h1>Структура веб-документу, базовий синтаксис HTML</h1>
    <p><strong>HTML</strong> (від англ. <u>HyperText Markup Language</u> - "мова розмітки гіпертексту"). <strong>Гіпертекст</strong> — це текст, який містить посилання на інші документи.</p>
    
    <hr>
    
    <h2>Деякі теги форматування тексту:</h2>
    <ul>
        <li><b>br</b> - перехід на новий рядок</li>
        <li><b>b</b> – <b>напівжирний текст</b></li>
        <li><b>strong</b> - <strong>напівжирний текст</strong></li>
        <li><b>i</b> - <i>похилий текст (курсив)</i></li>
        <li><b>u</b> - <u>підкреслений текст</u></li>
        <li><b>hr</b> - горизонтальна лінія</li>
    </ul>
    
    <hr>
    
    <p><strong>Перший абзац.</strong> Тег <b>P</b> є блоковим елементом, завжди починається з нового рядка, абзаци
    тексту, що йдуть один за одним, розділяються між собою відбивкою.</p>
    
    <p><strong>Другий абзац. Вивчення рівнів заголовків H1-H2:</strong></p>
    <h1>H1 - заголовок першого рівня</h1>
    <h2>H2 - заголовок другого рівня</h2>
    <h3>H3 - заголовок третього рівня</h3>
    <h4>H4 - заголовок четвертого рівня</h4>
    <h5>H5 - заголовок п’ятого рівня</h5>
    <h6>H6 - заголовок шостого рівня</h6>
